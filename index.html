🎼 Chord Chart Creator

❓ Keyboard Shortcuts

Ctrl + 1…9Divide the selected cell into 1–9 beat-cells (Ctrl+1 returns it to one cell)
Ctrl + 0Divide the selected cell into 10 beat-cells
Ctrl + SpaceAdd one beat-cell division and focus the new beat-cell
[ / ]Insert a cell to the left / right of the selected cell
\Remove the selected cell (a row must keep at least one cell)
z / ZEnter a quarter-rest symbol
x / XMark the selected cell as skipped (gray background with red cross)
SpaceWhile editing a chord, save it and move right
EnterWhile editing, save the chord and move to the next row; when a cell is selected, begin editing
Shift + EnterWhile editing, toggle the row's bottom line and move down
Arrow keysNavigate left/right between cells and up/down between rows and section headings; Down at the bottom creates a new row
Tab / Shift + TabMove right / left between cells
F2Edit the selected cell
PageUp / PageDownAdd a row above / below when a cell (not a text editor) is selected
Ctrl + LToggle the selected row's bottom-line thickness
Ctrl + EnterAdd a new section
Section name EndMarks the end of the chart and removes all content below it
Ctrl + HOpen Help
Ctrl + SSave song as a named JSON file
Ctrl + OOpen a JSON song file
Ctrl + IInsert image
Ctrl + DeleteDelete the selected row or section and its contents
Remove SectionRemove the current section and all rows/images up to the next section
Ctrl/Cmd + C / VCopy / paste the selected beat-cell's chord
DeleteClear the selected chord; while editing, clear the chord and keep the editor active
EscapeCancel the current chord edit and restore its previous value; close Help if it is open
