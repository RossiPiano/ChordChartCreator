❓ Keyboard Shortcuts

Ctrl + 1…9Divide the selected cell into 1–9 beat-cells (Ctrl+1 returns it to one cell)
Ctrl + 0Remove all beat-cell divisions from the current bar-cell
Ctrl + SpaceIn a bar-cell, add one beat-cell division; in a section-cell, open its right-aligned note field
Ctrl + Shift + SpaceRemove one beat-cell division from the current bar-cell, if at least two remain
Ctrl + Z / Ctrl + YUndo / Redo chart changes (Ctrl + Shift + Z is also supported as Redo, but Ctrl + Y is the more reliable alternative in some browsers)
Ctrl + EToggle Edit Mode / Play Mode
Alt + =Transpose every chord symbol in the chart up 1 semitone, using sharp enharmonic spellings
Alt + -Transpose every chord symbol in the chart down 1 semitone, using flat enharmonic spellings
Alt + 0Restore the chord symbols saved before the current transposition cycle
Alt + Enter (section name / left note)Open or insert a new line in the left-aligned multiline note below the section name
Ctrl + Space (section-cell)Focus the right-aligned multiline note
Alt + TTurn the current bar row into a yellow multiline notes-cell; press again on a section-cell to restore its normal section color. Works on the initial top section too.
Enter (yellow notes-cell)Insert a new line; arrow keys move the text caret normally. This cell does not create chord rows.
Ctrl + Up / Ctrl + Down (yellow notes-cell)Move out of the yellow notes-cell to the row above / below
Ctrl + Delete (yellow notes-cell)Remove only the yellow notes-cell; keep following rows, which inherit the previous section color. The permanent top section-cell is cleared instead.
Shift + SpaceInsert a space at the end of the current bar-cell, beat-cell, or section name
[ / ]Insert a cell to the left / right of the selected cell
\Remove the selected cell (a row must keep at least one cell)
z / ZEnter a quarter-rest symbol
x / XMark the selected cell as skipped (gray background with red cross)
SpaceSave the chord and move right; at the last cell, move to the next visual row
EnterMove to the next visual row; at the bottom of the chart, create a row below. With a selection, move below its bottom-left edge.
Shift + EnterCreate a new chord row below, visually separated from the current group
Shift + Alt + EnterSeparate the next row below from the current row without adding or removing rows; move to that next row
Shift + Alt + DeleteConnect the current row to the row above without adding or removing rows; move to the row above
Ctrl + Shift + EnterInsert a new row below the current row; disabled in yellow notes-cells
Arrow keysNavigate left/right between cells and up/down between rows and section headings; Arrow keys never create rows
Tab / Shift + TabMove right / left between cells; at row edges, continue to the next/previous row
F2Edit the selected cell
Shift + Arrow keysExtend a rectangular cell selection in Edit Mode
Arrow keys / Enter (with selection)Clear the selection and move outside its edge: Right from the top-right, Down or Enter below the bottom-left, Left from the top-left, or Up above the top-left. Navigation stops at the chart boundary and never creates a row.
Ctrl/Cmd + clickSelect or deselect individual cells, including nonadjacent cells
PageUp / PageDownAdd a row above / below when a cell (not a text editor) is selected
Ctrl + LToggle the selected row's bottom-line thickness, then move to the next visual row below
Ctrl + EnterCreate a new section heading below the current position; in a yellow notes-cell, create a normal section below it
Enter (section name)Create the section’s first row if needed, then focus its first (leftmost) cell
Section name EndMarks the end of the chart and removes all content below it
Ctrl + HOpen Help
Ctrl + SSave the song as a JSON file
Ctrl + OOpen a JSON song file
Ctrl + IInsert image
Ctrl + DeleteOn a section-cell, remove only that heading and let its rows inherit the previous section color; on a chord row, delete that row
Ctrl + Shift + DeleteDelete the entire current section, including its rows and images
Hamburger menuProvides touch-accessible controls for editing, transposing the whole chart, row and section operations, cell divisions, chord entry, notes, images, copy/paste, undo/redo, and song files
Remove SectionRemove the current section and all rows/images up to the next section
Ctrl/Cmd + C / VCopy / paste selected cells or ranges in Edit Mode
DeleteClear the selected chord; while editing, clear the chord and keep the editor active
EscapeCancel the current chord edit and restore its previous value; close Help if it is open
