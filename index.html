My Chord Chart

Select a chord cell or row, then use the top toolbar to add a chord row above/below or remove the selected row. Type in a chord cell to replace its content; double-click or press Enter/F2 to edit. Use arrow keys to move, Tab to move right, and Delete/Backspace to clear. Ctrl+C / Ctrl+V copies and pastes a single chord cell. Select a row before inserting an image to place it after that row.
